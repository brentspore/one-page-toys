Run `node scripts/indexnow-submit.mjs`, or pass paths for a subset, or `--dry-run`. ⚠ **Bing/Yandex/Seznam/Naver only — Google does NOT participate.** ⚠ **Re-run it after adding a toy** — that's the whole point, it beats waiting for a crawl.

## Standing exclusions and commit discipline

- **Never stage** `.claude/settings.json` / `.claude/settings.local.json`, `toys/shuriken-night-visual-pass/`, or `.DS_Store`. `git pull` before any commit; check `git status` for another session's working-tree state before staging (working-tree-only work would be destroyed by checkout/stash/clean).
- **Never run `scripts/sync-registry-paths.cjs`** — it's a one-off migration that sorts/corrupts the registry (`reference.md` wrongly lists it as routine). Register toys by hand (prepend, dir-form path) + `scripts/build-sitemap.cjs` (safe, read-only on the registry).
- `/archive/` is legacy: intentionally left on old unversioned favicon refs; sweeps must exclude it (BSD grep gotcha: paths lack `./`, so `grep -v /archive/` can fail to match).

- **Directory URLs everywhere:** canonical/og:url/JSON-LD/registry path/sitemap use `onepagetoys.com/toys/<slug>/`; back-links `../../`. `all-toys/` is a directory (bump `all-toys/index.html`; root `all-toys.html` is an unlinked leftover). Per-category pages `all-toys/<cat>/` carry static meta + a `data-cat` body attr main.js reads.

- **Badges:** tip-jar/fullscreen default right-center; when that blocks play, dock bottom-right with the doubled-class CSS override + center→corner entrance slide (nova-coil pattern). Tickets pill is bottom-LEFT and self-docks above the back-link via measured `dock()`.
- **New-toy pipeline:** self-contained `toys/<slug>/` (SEO + JSON-LD + GA + no-flash theme init + tip-jar/share includes); registry prepend; sitemap; `TYPE_NL_PHRASES`; card CSS rule + `:not()` chain; og-gen entry (+`light:true` for light backgrounds); REAL rendered card then OG (og-gen pulls the card as motif — **card first**); ticket rule if it stores a best; hub cache-bust across all 8 hub pages. Full checklist: `~/.ai/skills/new-toy`. Multi-toy builds: parallel subagents write ONLY `toys/<slug>/`, parent does all shared registration serially.
- **Quality bars** (owner is a designer): every toy interactive, its own curated world, real rendered card that reads as the toy, never ship without an OG, always screenshot and LOOK. Audio: layered physically-grounded voices + convolver space + stereo + compressor, consonant scales, iOS unlock + toggle; headless cannot hear — audio is always "needs owner ears". Full recipes in `.ai/memory/DECISIONS.md`.
- **Verification gotchas:** capture canvas at `deviceScaleFactor: 1` (Playwright tears at 2); headless forces reduced-motion; headless rAF throttles (drive frames via `evaluate(rAF)` loops); sim vs wall time diverge — probe internal state, not timed screenshots; force-clicking hidden chrome hits the canvas underneath; `getByteFrequencyData` saturates — use `getFloatFrequencyData` and read a tone's own partial bins; grep-clean temp debug hooks before commit.
